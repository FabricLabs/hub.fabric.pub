# Changelog
All notable changes to **hub.fabric.pub** (Fabric Hub) are documented here. RCs are coordinated with **`@fabric/core`** and **`@fabric/http`**.

## [Unreleased]
- **PR #16 review nits:** `report:install` removes `package-lock.json` (instead of writing a blank line into it). Heap cap helpers return a trimmed copy instead of `delete map[key]`. Message-log restore basename-only reads + `parseFilesystemJson` for STATE. Docs record lockfile `@fabric/core` **`9938917`** / `@fabric/http` **`7d7f1c7`**.
- **Boot noise (not the heap root):** managed Lightning is opt-in (`lightning.managed` / `lightning.enable`, plus `lightningd` on PATH). `scripts/hub.js` datadir-only settings no longer spawn CLN (10 sock retries per life). Ops: `pm2-logrotate`, drop dead `sensemaker.io:7778` seed, Hub Node **24.15.x** — [PRODUCTION.md](docs/PRODUCTION.md).
- **Heap OOM (desktop Electron):** `npm run desktop` loads `node_modules/@fabric/core` (not a `link:fabric` tree). That pin’s `Filesystem.publish` still retains every body and `synchronize()`s. Hub now wraps `fs.publish` → `writeFile` (`functions/hubFilesystemPersist.js`) so Payjoin, federation registry, contract queue, identity cluster, and document writes cannot retain. Tip indexing uses one `getblock` (verbosity **1** unless tx documents or regtest federation scan need **2**) instead of two verbosity-2 calls. Local crash: ~844 s / ~3671 MiB mark-compact; Beacon never started (`beacon/NETWORK` guard); `sensemaker.io:7777` timeout is a dead seed, not the leak. Restart desktop after this; `npm run link:fabric` still picks up the core Filesystem cut. Do not raise `--max-old-space-size`.
- **Heap OOM (playnet Hub):** `Filesystem.publish` no longer retains bodies or re-syncs the tree (core). Hub `commit()` writes `STATE` with `writeFile` (not `publish`), stringifies `_state.content` after capping Activity (`256`) and the in-memory Fabric message map (`2048`). Merkle leaves are payload hashes. P2P BitcoinBlock ingest uses a bounded tip set. Oversized `STATE` snapshots skip JSON restore and reload a window from `messages/*.json`. Pins `992ea478` / `f1b5e147` / `1b162e35` were already live and did not stop the loop. Do not raise `--max-old-space-size`. Tests: `tests/hub.heapBounds.test.js`.
- **GetDocument Buffer JSON:** `Filesystem.readFile` returns a Buffer; Hub now JSON-parses Buffers (same as strings, including `Uint8Array`) so held files expose `contentBase64`. The old `typeof raw === 'string'` branch returned the Buffer as the document, which made document-network / fabric-epic e2e wait helpers report `no document`. Wait diagnostics treat an empty-string `contentBase64` as a payload mismatch, not a missing body.
- **Shared-mode http fallbacks:** when `@fabric/http/functions/httpSharedMode` omits `isHttpSharedModeEnabled` / `resolveHttpListenHost` / `DEFAULT_HTTP_LISTEN_ENV_KEYS`, Hub uses the local implementations (not only `applySharedModeWebsocketGate`). Local listen-host matches http: constructor `host` beats inherited `INTERFACE`.
- **BIP-69 PSBTs:** unsigned Hub builders sort vin/vout with `@fabric/core/functions/bip69` before the first signature (crowdfund payout, original Payjoin PSBT, Bitcoin `_buildPSBT`). Payjoin ACP still appends the Hub input and does not reorder signed slots.
- **Operator Accept:** `AcceptTrackedApplicationContract` / `RejectTrackedApplicationContract` verify Schnorr `OP_IDENTITY`/`admin` tokens against Hub `_rootKey` **or** the Fabric Peer identity (`agent.key`). Local developer `FABRIC_XPRV` is the production publisher. Missing token → `adminToken required`; bad signature → `adminToken invalid`. Hub-level tests bypass `setup.verifyAdminToken` (`tests/hub.operatorAccept.test.js`).
- **Peer / Bitcoin debug flood:** do not `console.debug` every Fabric Peer `debug` event, and do not `console.log` Bitcoin `debug`, unless `settings.debug` / `FABRIC_HUB_DEBUG`. Truncate at 2 KiB. Do **not** force `bitcoin.settings.debug = true` after start (that re-enabled per-RPC debug strings on production). Lightning `debug` is gated the same way.
- **Bulk security-advisory ingest:** drop OpenSSF / GHSA malware dumps (`security_advisory`, `@zalastax/nolb-*`, “Malicious code in @…”) on `CreateDocument`, `EditDocument`, P2P file receive, inventory resync, and `recordActivity`. JSON arrays of advisory objects recurse (cap 32). Those Internal-message floods OOMed production Hub. Pair with `@fabric/http` Internal-log + commit snapshot cuts.
- **Chat shoutbox:** WebRTC → Fabric TCP `P2P_RELAY` inner chat is UTF-8 text (legacy JSON `{ object.content }` envelopes are unpacked via `@fabric/core/functions/fabricChatText`). Registry marks `P2P_CHAT_MESSAGE` as `utf8-text`; author is AMP signature.
- **Identity paths:** Hub re-exports `fabricIdentityAccountPath` (core helper when the pin exports it). Receive leaf stays `fabricIdentityDerivationPath`.
- **Identity cluster:** ingest keys must be compressed or x-only hex (`pubkeyXOnly`); colon-smashed strings are `invalid pubkey`.
- **Beacon:** Hub ready-round retry tests match core recovered-witness checks (real Schnorr; fake `'00'` is rejected).
- **Device link:** per-origin create quota is in `@fabric/http` (`MAX_SESSIONS_PER_ORIGIN`); Hub re-exports it from `functions/fabricDeviceLink.js`. Browser device-link fetch omits client-set Origin/Referer.
- **Site login:** expired `GET /sessions/:delegationToken` requires matching `Authorization: Bearer` (http pin).
- **Pins:** `@fabric/core` lockfile `9938917804e2bf5ba5cf1fab7bf0975129d9063f` (Filesystem publish retain cut + production follow-ups from [#185](https://github.com/FabricLabs/fabric/pull/185); MuSig2 `autoAccept` default off, BIP-21 `req-*`, collection cwd-containment, Codacy `Number('…')` literals; plus MuSig2/BIP helpers, IPv6 candidate `[host]:port`, generic-message debug exact-match, exported `fabricIdentityAccountPath`, AMP wire name wins over inventory JSON `type: 98`); `@fabric/http` lockfile `7d7f1c7c918dabe7f2ae59d638b16e1a020d08bd` (POST-null 400, device-link DELETE cancel `ok: false`, 402 blob-id omit, CLI `fabricHomeEnv` before `Environment.start()`, Internal-log/commit snapshot cut, `fabricChatText` re-export, `pubkey@` strip + dedicated-NIC `:7778`→`:7777`, unicast `FABRIC_INTERFACE` sibling-NIC self-filter, Bearer path-token). `package.json` stays on `#feature/rsi`. `report:install` removes `package-lock.json` then `npm i --allow-git=all`. `scripts/hub.js` loads `~/.fabric/env` via `fabricHomeEnv` (process env wins). Playnet `loadPeerKeySettings` rethrows unless `MODULE_NOT_FOUND`; fallback keeps raw `FABRIC_SEED` hex as `{ seed }`.
- **Managed Bitcoin:** Hub RPC probe keeps cookie credentials (no longer a port-only stub that 401s an orphan `bitcoind`). Spawn early-exit / datadir lock **attaches** to the live node instead of `pm2` crash-looping. Shutdown kills only a Core this process spawned.
- **Playnet:** `npm run playnet:status -- --production` reports native `fabric-beacon` plus an optional sibling GoonCitizen contract id. Deploy the application namespace from GoonCitizen: `npm run playnet:deploy-gooncitizen -- --production --accept`.
- **SPA assets:** `assets/scripts/assets/manifest.json` loads the same-origin `/bundles/browser.min.js` (no remote `fabric.pub` script URI).

- **Document Market (opt-in):** Accumulate peer document inventories (`FABRIC_DOCUMENT_MARKET_ACCUMULATE=1`) and republish **held** files at a markup (`FABRIC_DOCUMENT_MARKET_REPUBLISH=1`, default +10%). Offer book on Documents; RPC `ListDocumentOffers` / `RefreshDocumentMarket`; reusable helper `@fabric/hub/functions/documentInventoryMarket`. Outbound inventory still lists only local blobs. See [PAYMENTS_PROTOCOL.md](PAYMENTS_PROTOCOL.md) phase **J**.
- **Dependencies / security:** Align with `@fabric/http` / `@fabric/core` Node **24.15.0**. Bump `ws@8.21.2`, `webpack@5.109.2`, `webpack-dev-server@5.2.6`, `nodemailer@9.0.4`, `electron@39.8.10`, `electron-builder@26.15.7`, `react-router-dom@7.18.2` (drop unused `Switch` imports); add direct `terser-webpack-plugin` for the webpack config. Overrides: `ws`, `uuid@11.1.1`, `tar@7.5.22`, `builder-util-runtime@9.7.0`. See [AUDIT.md](AUDIT.md) (RSC CSRF residual accepted for SPA `BrowserRouter`).
- **Browser bundle / React Router 7:** Webpack `conditionNames` no longer prefer `import` (which selected react-router `.mjs` and crashed the SPA with `__webpack_modules__[id].call is not a function`). Alias CJS entrypoints for `react-router` / `react-router-dom`; `BrowserRouter` uses RR7 `useTransitions` instead of obsolete v6 `future` flags.
- **npm git deps:** `.npmrc` / `report:install` use **`allow-git=all`** so nested Hub→http→core git preparation (commit SHAs) is not refused under npm 12+.
- **UI (Fomantic / Semantic):** The packaged site theme is renamed from **`sensemaker`** to **`fabric`**. **Arvo** `.woff2` are maintained via `@fabric/http` `make:fonts` / `build:semantic`; Hub uses `npm run build:semantic` (delegates to the dependency). The old `themes/sensemaker` tree was removed.
- **Document market × L1 index:** Auto-publish **Bitcoin block** (+ optional **tx**) Fabric documents with **immutable** canonical JSON (**schemaVersion 3**) for stable inventory HTLC / `DocumentPublish` preimages; default **`purchasePriceSats`**; **prune-aware** local catalog when `bitcoind` is pruned; Bitcoin status **`bitcoinPruned`** / **`bitcoinPruneHeight`**; roadmap [docs/PRODUCTION_ROADMAP.md](docs/PRODUCTION_ROADMAP.md), protocol [PAYMENTS_PROTOCOL.md](PAYMENTS_PROTOCOL.md) phase **I**.
- **Settings / Bitcoin UX:** Identity vs Hub wallet callouts on Settings (Bitcoin wallet) and Bitcoin page; **operator deposits checklist** when L1 is up; **Hub Bitcoin backend unavailable** when upstream is configured but RPC is down. **Backup** line links to Security.
- **Settings:** `FABRIC_BITCOIN_ENABLE=false` skips the Bitcoin service (headless E2E without Core). **`FABRIC_PORT`** coerced to a number in `settings/local.js` so Fabric Peer binds to the intended port.
- **CI:** Workflow **E2E RC** (`.github/workflows/e2e-rc.yml`) — browser E2E + `scripts/ci-e2e-payjoin.sh` on tags `v*` and manual dispatch; isolated `FABRIC_HUB_USER_DATA`, `FABRIC_PORT=17777`, `FABRIC_BITCOIN_ENABLE=false` for Payjoin script.
- **Settings:** Fix `/settings` crash (undefined Peers gate variable); align with `TopPanel` using `readHubAdminTokenFromBrowser()` as `hasHubAdminPeerNav`.
- **Roadmap:** [docs/PRODUCTION_ROADMAP.md](docs/PRODUCTION_ROADMAP.md) — phased plan for wallet, crowdfunds/federation, Payjoin+Lightning; production feature-flag JSON example.
- **Home / Bitcoin:** **Treasury** shortcut on Home → Bitcoin page anchor `#fabric-bitcoin-payjoin` (or Lightning when Payments flag off); Payjoin segment `id="fabric-bitcoin-payjoin"` for deep links.
- **Federation settings:** `id="settings-federation-heading"` on Distributed federation page for tests and anchors.
- **Admin / operations:** Added worker queue API + Admin controls (`GetWorkerStatus`, `ListWorkerQueue`, `RunWorkerQueueNow`, `DropWorkerQueueItem`, `ClearWorkerQueue`) and a node-wealth panel (`GetNodeWealthSummary`) showing wallet balance and labeled earning flows.

## [0.1.0-RC1] — 2026-03-20
- **Release engineering:** `npm run ci`, [docs/PRODUCTION.md](docs/PRODUCTION.md), [docs/MARKETING_OVERVIEW.md](docs/MARKETING_OVERVIEW.md), [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md), GitHub Actions CI, README positioning.
- **Payments / documents:** Inventory HTLC preimage bound to canonical **`DocumentPublish`** envelope via **`@fabric/core/functions/publishedDocumentEnvelope`** (Hub [loader](functions/publishedDocumentEnvelope.js)); AES-GCM phase-2 delivery; Bridge chunk assembly + preimage unlock UI.
- **Document list:** `ListDocuments` adds **`storageL1Status`** (batched Bitcoin RPC: one mempool query + parallel `getrawtransaction` per distinct storage-contract txid); Documents UI shows mempool / confirmation depth beside the Storage contract link.
- **L1 payment verify:** **`GET /services/bitcoin/transactions/:txid?address=&amountSats=`** (consolidated into the transaction resource; no separate `.../payment-verification` path); removed **`POST .../verify-payment`** and **`POST .../payments/verify-l1`**. `verifyL1Payment` in **`functions/bitcoinClient.js`**; **`/services/bitcoin/resources`** UI.
- **Inventory HTLC on-chain claim:** Admin JSON-RPC **`ClaimInventoryHtlcOnChain`** — tapscript-path PSBT, sign with hub identity key, `sendrawtransaction`; helpers in `functions/inventoryHtlc.js`; `GetInventoryHtlcSellerReveal` returns **`claimTxid`** when present.
- **REST surface:** Payjoin create session is **POST `/services/bitcoin/payjoin/sessions`** (replaces **`/deposits`**); submit proposal is **POST `.../sessions/:id/proposals`** (replaces **`.../proposal`**). Lightning channel close is **DELETE `/services/lightning/channels/:channelId`** (replaces **POST `.../channels/close`**). `functions/bitcoinClient.js` and **`/services/bitcoin/resources`** updated; legacy **`/lightning/invoice|pay|decode`** fallbacks removed in favor of **`/invoices`**, **`/payments`**, **`/decodes`**.
